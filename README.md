# The Double Life

A detective adventure and stealth game developed in Godot 4.

## Overview
Play as Julian, balancing official investigative duties with clandestine night leads across the districts of Greyhaven.

## Project Structure
- `the-double-life/`
  - `project.godot`: Main Godot engine configuration file
  - `scenes/`: Game scenes organized by category (UI, Characters, Levels)
  - `scripts/`: GDScript source code for gameplay, UI, and core systems
  - `assets/`: Textures, audio, maps, character sprites, and tilesets
  - `data/`: Story and case JSON files
